## Infant God戦の基本システムとエンカウントダイナミクス

アリーナに足を踏み入れる前に、プレイヤーはこの戦闘でどのようにプレッシャーがかかるかを理解する必要があります。このボスは単なる標準的なHPプールだけでなく、「原初の生命力（Primordial Vitality）」と「コズミックレゾナンス（Cosmic Resonance）」からなる二重リソースシステムを採用しています。戦闘中にレゾナンスの蓄積を無視すると、アリーナ全体への即死全滅（ワイプ）攻撃を回避できなくなります。

### リソースシステムの概要

ボスは、チームがその宇宙テザー（結線）ギミックをどれだけ効果的に軽減できているかに応じて、いくつかの動的な状態を遷移します。

| ギミック / ゲージ | 機能 | 脅威度 | 対策・軽減戦略 |
| :--- | :--- | :--- | :--- |
| **原初の生命力 (Primordial Vitality)** | メインHPバー（3つのセグメントに分割） | 高 | 体勢崩し（スタッガー）中にバーストDPSを叩き込む |
| **コズミックレゾナンス (Cosmic Resonance)** | 毎秒チャージ。100%でアリーナ全体即死攻撃を発動 | 致命的 | ボスをスタッガーさせるか、浄化の柱（Cleansing Pillars）を作動させる |
| **クライングエコー (Crying Echo)** | 被ダメージを増加させる高周波音波デバフ | 中 | デバフを解除（ディスペル）するか、15mの間隔を維持する |
| **アストラルテザー (Astral Tether)** | 2人のプレイヤーをリンク。時間経過でダメージが増加 | 高 | 4秒以内に20m以上離れてテザーを切断する |

コズミックレゾナンスメーターの管理は、**Infant God戦**において最も重要な要素です。アリーナに入ったら、ボスのエネルギーが70%に達するたびに浄化ノードを作動させる専任のランナー（走者）を割り当ててください。これによりレゾナンスの蓄積がリセットされ、壊滅的なパーティダメージを防ぐことができます。

## ボスのフェーズ詳細とタイマー

戦闘は過酷な3つのフェーズに分かれており、段階的にギミックが激化し、攻撃速度が上昇、要求される実行精度もシビアになっていきます。

```
フェーズ1：微睡みの覚醒 (100% – 70% HP)
   │
   ▼
フェーズ2：コズミック・タントラム (70% – 30% HP)
   │
   ▼
フェーズ3：超越的神化 (30% – 0% HP)
```

### フェーズ1：微睡みの覚醒 (100% – 70% HP)

開幕フェーズ中、ボスはアリーナ中央から移動しません。求められる移動頻度は低いものの、広範囲に広がる空間の裂け目を避けるための正確な位置取りが極めて重要です。

*   **空間薙ぎ払い (Spatial Swipes):** 前方への広範囲な2連薙ぎ払いの後、頭上からの叩きつけを行います。タンクはボスをグループとは逆方向に向けることが必須です。
*   **星光の宝珠 (Starlight Orbs):** 最も遠い位置にいる2人のプレイヤーを追尾する弾を発射します。外周に沿って誘導（カイト）してください。
*   **オーラパルス (Aura Pulse):** 20秒ごとにパルスを放ち、軽微な基礎ダメージとスタックする被ダメージ増加デバフを付与します。

### フェーズ2：コズミック・タントラム (70% – 30% HP)

HPが70%になると、ボスは激昂状態に入り、移動速度が上昇してアリーナ全域を浮遊しながら移動するようになります。

| 攻撃名 | 詠唱時間 | 危険エリア | 対処法 |
| :--- | :--- | :--- | :--- |
| **アストラルクレードル (Astral Cradle)** | 2.5秒 | 360度拡大リング | ジャンプまたは外周の境界を越えて外側へダッシュ |
| **宇宙の掌握 (Grip of the Cosmos)** | 1.8秒 | 最高DPSプレイヤーに向けた扇状範囲 | ボスの当たり判定の後方へ横方向に回り込んで回避 |
| **超新星の慟哭 (Supernova Wail)** | 4.0秒（チャネル） | アリーナ全域 | 3.5秒以内に体勢ゲージを削り切って詠唱を中断 |
| **虚空断裂 (Tear the Void)** | 即時 | ランダムなプレイヤーの足元に渦を生成 | 中央から離れた位置に設置し、移動ルートを確保 |

### フェーズ3：超越的神化 (30% – 0% HP)

最終フェーズでは完璧な立ち回りが求められます。外周全体が崩落し、安全な戦闘エリアが40%縮小します。ボスは2つのアビリティを同時に発動するため、瞬時の判断が必要です。プレイヤーコミュニティの報告によると、すべての主要なクールダウンと消費アイテムのバフをこの削り（バーン）フェーズに残しておくことが、全難易度を通じて最も高いクリア率につながるとされています。

## 戦術的ポジショニングと段階的攻略手順

適切なエリアコントロールができるかどうかが、レイド成功グループと終わりのないワイプを繰り返すグループの分かれ目となります。規律ある配置を維持することで、移動の多いフェーズでも攻撃の手を止めずに済みます。

```
                    [ 北の浄化ノード ]
                            │
        [ 左側面 ]          │          [ 右側面 ]
       (遠隔DPS)            │         (ヒーラー)
                            │
[ 西の浄化ノード ] ──── [ ボス ] ──── [ 東の浄化ノード ]
                            │
                            │
                     [ タンク待機位置 ]
                            │
                    [ 南の浄化ノード ]
```

### 安定クリアのための実践手順

1.  **オープニング交戦:** タンクがヘイト（敵視）を確立し、ボスを北側の外周に向けます。近接DPSはボスの左側面背後に密集します。
2.  **レゾナンスサイクルの処理:** レゾナンスが50%に達したら、担当の遠隔ランナーは最も近い起動中の浄化ノードへ移動し、浄化発動の準備をします。
3.  **フェーズ移行の生存:** ボスのHPが70%および30%の境界に近づいたら、残っているデバフが解除されるまでバーストDPSを一時停止します。テザーが繋がったままフェーズを移行させると、ほぼ確実に死者が出ます。
4.  **ファイナルバーン手順:** HPが30%になったら、すべての攻撃バフを発動し、戦闘ペットを召喚し、致命的でない足元の裂け目は無視して、レゾナンスがパーティを全滅させる前に残りのHPを一気に削り切ります。

**Infant God戦**におけるポジショニングを極めるには、パーティメンバー全員の忍耐、規律、そして明確な連携が不可欠です。

## よくあるミスとその対策

経験豊富なグループであっても、この戦闘特有のギミックの重なりで躓くことがよくあります。以下に、プレイヤーの経験に基づいた最も一般的な失敗要因と直接的な解決策をまとめました。

| よくある失敗要因 | 根本的な原因 | 即効性のある解決策 |
| :--- | :--- | :--- |
| **レゾナンス100%での即座全滅** | ランナーによるノード作動の遅れ | メインランナーがテザー対象になった場合に備え、サブのランナーを2名事前に決めておく |
| **フェーズ2で近接DPSが一撃死** | アストラルクレードル発動時にボスの前方扇状範囲に残っている | 常に側面の位置取りを維持する。正面を横切って背後を狙いに行かない |
| **フェーズ3でのヒーラーのマナ枯渇** | クライングエコーによる回避不能な継続ダメージ | 最終削りフェーズ中、15秒ごとにグループ全体の防御クールダウンを順番に回す |
| **テザーの爆発事故** | 繋がれたプレイヤー同士が同じ方向に走ってしまう | 「北/西は左へ、南/東は右へ」といった厳格な移動ルールを設定しておく |

これらの落とし穴を事前に把握しておくことで、チームの攻略手順を洗練させ、**Infant God戦**での無駄なワイプを無くすことができます。

## よくある質問（FAQ）

### Infant God戦で最も危険なギミックは何ですか？
フェーズ2で詠唱される**超新星の慟哭 (Supernova Wail)**が最も危険な単体ギミックです。4秒間の詠唱が完了する前に、全員で連携して即座にスタッガーダメージを与えて中断させる必要があります。中断に失敗すると回避不能の全体即死攻撃となります。

### Infant God戦はソロでクリアできますか？
基本的にはエンドゲームのグループ向けコンテンツとして設計されていますが、高い自己回復能力、強力なデバフ解除手段、およびテザーやノード操作のギミックを単独で処理できる瞬間移動スキルを備えたビルドであれば、ソロクリアも可能です。

### この戦闘で最も重要な属性耐性は何ですか？
宇宙（Cosmic）耐性と音波（Sonic）耐性の2つが極めて重要です。ボスのオーラによる継続ダメージや環境パルスを軽減するため、装備全体で最低でも20〜30%の宇宙ダメージ軽減を確保することを目指してください。

### コズミックレゾナンスメーターの蓄積を止めるにはどうすればよいですか？
アリーナ各地で順次起動する外周の「浄化ノード（Cleansing Nodes）」を作動させることで、1つのノードにつき蓄積されたレゾナンスゲージを40%減少させることができます。メーターが75%に達する前に作動できるよう、ランナーの割り当てを連携しておきましょう。
