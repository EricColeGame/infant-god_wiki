商人はあなたの未熟さをあざ笑い、旧信仰の司教たちを倒しながらその魂に永遠の安らぎを与えていない「幼き神」だと決めつけます。この不均衡を正すため、プレイヤーは神聖な契約を結ぶことになります。すなわち、4つの主要領域を再訪して強化された司教たちを撃破し、「神の涙（God Tears）」と呼ばれる古代の通貨と引き換えに神聖な宝物を手に入れるのです。

## 幼き神 完全攻略チャート：ステップごとの進行手順

未熟な神から誰もが認める死の神へと昇格するには、決まった一連の目標を達成する必要があります。以下のステップ別ロードマップに沿って、クリア後のメインストーリーを進めましょう。

```
待ち受けし者を撃破 ➔ ミスティック・セラーと遭遇 ➔ 商人に名前を付ける 
➔ 煉獄 / 聖戦をクリア ➔ 4人の司教と再戦・撃破 ➔ 「死の神の羊皮紙」を獲得
```

### 1. 神聖な契約の締結
クリア後の最初の会話を終えたら、新しくなった聖戦に出発しましょう。強化されたゾーンでいずれかのミニボスを倒すと、最初の「神の涙」が手に入ります。拠点に戻ると商人がその功績を認め、彼らにカスタムの名前を付けるよう求めてきます。

### 2. 司教たちの解放
メインクエストでは、ダークウッド、アニュラ、アンカーディープ、シルククレードルを再び冒険することになります。司教たち（レスシー、ヘケト、カラマール、シャムラ）は体力が大幅に増加し、攻撃チェーンが激化し、追加のトラップやギミックを備えています。

| 領域 | 司教ボス | 解放される信者特性 | 撃破後の対話テーマ |
| :--- | :--- | :--- | :--- |
| **ダークウッド** | レスシー（再戦） | 混沌と盲目的な献身 | 混沌とした初期の昇天 |
| **アニュラ** | ヘケト（再戦） | 無慈悲な飢え | 獰猛で凶暴な本性 |
| **アンカーディープ** | カラマール（再戦） | 臆病と敏捷 | 聞く耳を持たない頑固さ |
| **シルククレードル** | シャムラ（再戦） | 戦術的知恵 | 悲劇的な知性の失墜 |

### 3. 究極の恩恵の獲得
4柱の神をすべて鎮めて拠点に戻り、名付けた商人に話しかけましょう。本編のキャンペーン中に「待ち受けし者」をどう処分したかによって、異なる報酬が得られます：
- **待ち受けし者を生かした場合**：「待ち受けし者のトロフィー」の装飾設計図と**死の神の羊皮紙（God of Death Fleece）**を獲得。
- **待ち受けし者を処刑した場合**：商人がナリンデルを専用の信者形態として拠点に直接届けてくれ、同時に**死の神の羊皮紙（God of Death Fleece）**を獲得。

## 「神の涙」の効率的な収集と使い方

この**幼き神 攻略**の主軸となるのは、「神の涙」を集めて商人のルーレットを回すことです。神の涙は、未取得の教条（Doctrine）、限定信者スキン、強力な遺物（Relics）をアンロックするためのクリア後最重要通貨です。

### 神の涙の入手方法
- **聖戦のミニボス＆ボス**：強化された聖戦ボスを倒すと、確定で「神の涙」が1個ドロップします。
- **煉獄（Purgatory）モード**：煉獄の日替わりランをクリアすると、拠点の時間を進めることなく「神の涙」を獲得できます。
- **信仰度レベルアップ**：信仰度上限に達した忠誠度の高い信者のレベルをさらに上げると、涙の破片が手に入ります。

| ルーレット報酬アイテム | 基本確率 | 排出プール制限 | 用途 / 効果 |
| :--- | :--- | :--- | :--- |
| **忘れ去られた戒律石の破片** | 約40%（初期） | 最大24個（DLC導入で28個） | 二者択一で取得できなかった教条を解放 |
| **特別な信者形態** | 約20% | 排出上限あり | 限定の見た目を解放（例：コアラ、エビなど） |
| **拠点の装飾** | 約20% | 排出上限あり | 宇宙や神聖をテーマにした装飾品の設計図 |
| **聖なる護符の破片** | 約20% | 排出上限あり | 残りの羊皮紙（Fleece）をアンロックするために使用 |
| **レアな首輪** | 枯渇した枠に出現 | 無限入手可能 | 不老不死、悪魔ボーナス、忠誠度バフなどを付与 |

> **プロの裏技（プレイヤー検証済み）：** コミュニティの報告によると、ミスティック・セラーに「神の涙」を渡す直前にゲームをセーブしておくことができます。もしルーレットで今必要のないアイテムが出た場合、メインメニューに戻ってロードし直すことで、通貨を失わずに報酬を引き直す（リセマラする）ことが可能です。

この**幼き神 攻略**の段階では、戦闘の難易度が大幅に跳ね上がります。敵の攻撃力が増大し、弾幕パターンが複雑に重なり合い、ボスアリーナには頻繁に爆発系のギミックが発生します。

### クリア後のおすすめ最強ビルド
強化された司教たちを素早く撃破するために、テレポート前にビルドを最適化しておきましょう。

| ビルド要素 | 推奨装備・選択 | 戦略的メリット |
| :--- | :--- | :--- |
| **羊皮紙（Fleece）** | 運命の羊皮紙 / 黄金の羊皮紙 | 開幕からタロット効果を最大化、またはノーダメ継続でダメージ超スケール |
| **メイン武器** | 神聖の斧 / 吸血の blunderbuss（ラッパ銃） | 高い基礎バースト火力、または長期戦での持続的なHP回復 |
| **呪文** | 運命の猟犬（Hounds of Fate） / 神聖な爆発（Divine Blast） | 長距離ホーミング弾による安全な攻撃、または群がる雑魚敵に対する無敵時間 |
| **悪魔信者** | ヴェスタ（熱意回収）＋ パエアン（追加ハート） | ボスの大ダメージを耐えつつ、呪文の連続発動を維持可能 |

### 再戦時の重要な立ち回り
1. **増援の雑魚敵を即座に処理する**：強化された戦闘では、取り巻きのエリート敵が出現します。広範囲の呪文を使用して、回避ルートが塞がれる前に一掃しましょう。
2. **無敵時間（I-Frames）を活用する**：ボスの弾幕密度は本編のほぼ2倍になります。単にダッシュで逃げるのではなく、ローリングの無敵時間を利用して弾幕をすり抜ける意識を持ちましょう。
3. **練習場として煉獄を活用する**：毎日の煉獄ランを積極的に活用してください。煉獄をプレイしている間は拠点の時間が完全に停止するため、教団の信者を飢えさせる心配なくボスの攻撃リズムを練習できます。

## よくある質問（FAQ）

### 『Cult of the Lamb』で「幼き神」のクエストラインはどうすれば発生しますか？
このクエストラインは、メインストーリーで「待ち受けし者」を倒した直後に始まります。聖戦のゲートに戻るとミスティック・セラー（`???`）が現れ、あなたを「幼き神」と呼び、クリア後の再戦聖戦がアンロックされます。

### ミスティック・セラーから入手できる「忘れ去られた戒律石」の最大数はいくつですか？
ゲーム本編では、ミスティック・セラーから最大24個の「忘れ去られた戒律石」を入手できます。Woolhavenなどの大型DLCを導入している場合、この上限は28個に増加し、教団の相反するすべての教条を完全に解放できます。

### この攻略チャートを進めると4人の司教全員を信者として勧誘できますか？
はい。この**幼き神 攻略**に従い、それぞれの聖戦ゾーンで各司教を2度撃破すると、彼らの魂が浄化されます。撃破後、司教たちは専用スキンを持つユニークなレジェンダリー信者として教団の拠点に現れます。

### 「神の涙」を持たずに商人に話しかけるとどうなりますか？
インベントリに「神の涙」が1つもない状態でミスティック・セラーに話しかけると、騙そうとするなと厳しく警告されてあしらわれます。デバフなどのペナルティはないため、再び聖戦や煉獄をクリアして涙を集めてから戻ってきましょう。
