## 称呼你为“幼神”的神秘实体是谁？

击败“待终冠主”（The One Who Waits）后，通往最终决战区域的传送门会被一位正式命名为 `???`（通常被称为神秘商人 / Mystic Seller）的神秘商人取代。这位商人身披流淌着星空与黑色浓汁的宇宙斗篷，声称自己自世界诞生之初便已存在。

商人随即会嘲笑你的稚嫩与经验不足，称你为一个斩杀了古老信仰主教却未能让其灵魂得到安息的“幼神”。为了纠正这种失衡，你将与其签订一份神圣契约：重访四大主要区域，击败获得强化的主教们，并使用名为“神之泪”（God Tears）的远古货币兑换神圣宝藏。

| 实体特征 | 游戏内详情 |
| :--- | :--- |
| **官方文件名称** | Mystic Seller（神秘商人）/ `???` |
| **位置** | 圣殿基地传送门（原通往待终冠主处） |
| **主要功能** | 终局任务发布者 & 幸运转盘商人 |
| **接受货币** | 神之泪（God Tears） |
| **特殊互动** | 尝试偷窃或绕至其身后会引发愤怒对话并扣除红心上限 |

### 警告：尊重商人的领地
如果你试图反复走到商人身后，他们会用奥术符号斥责你。若继续强行穿过，你的生命值上限将被暂时扣除一颗红心容器，直到你开启下一次圣战才会恢复。

## 幼神全流程攻略：分步通关指南

从一个羽翼未丰的初生神明蜕变为无可争议的死神，需要完成一系列严格的目标。请按照以下步骤路线图完成通关后的主要剧情。

```
击败待终冠主 ➔ 会见神秘商人 ➔ 为商人命名 
➔ 完成炼狱/圣战 ➔ 再次击败4位主教 ➔ 获取死神圣洁长袍
```

### 1. 达成神圣契约
在完成通关后的首次对话后，踏上你的第一次强化圣战。在重置后的区域中击败任意小Boss即可获得你的第一枚神之泪。返回基地后，商人会认可你的功绩，并要求你为其赋予一个自定义名称。

### 2. 解放主教们的灵魂
你的核心任务是再次深入暗林（Darkwood）、无尾林（Anura）、深渊沼地（Anchordeep）和蛛丝秘境（Silk Cradle）。四位主教——莱靹（Leshy）、赫凯特（Heket）、卡拉玛（Kallamar）和沙穆拉（Shamura）——如今拥有更高的生命值上限、更具侵略性的连击招式以及额外的场地危险机制。

| 区域 | 主教Boss | 解锁的信徒特质 | 击败后的对话主题 |
| :--- | :--- | :--- | :--- |
| **暗林** | 莱靹（重赛） | 混乱与盲目狂热 | 混乱的早期飞升 |
| **无尾林** | 赫凯特（重赛） | 无情饥渴 | 凶猛残暴的本性 |
| **深渊沼地** | 卡拉玛（重赛） | 怯懦与迅捷 | 顽固拒绝倾听 |
| **蛛丝秘境** | 沙穆拉（重赛） | 战术智慧 | 悲剧性的智识陨落 |

### 3. 获取终极赐福
在制服所有四位神明并返回基地枢纽后，与已命名的商人交谈。根据你在主线战役中对待终冠主的处理方式，你将获得不同的奖励：
- **宽恕/放过待终冠主**：获得**待终冠主奖杯**装饰蓝图以及**死神圣洁长袍**（God of Death Fleece）。
- **处决待终冠主**：商人会将纳林德（Narinder）以专属信徒形态直接交付给你作为永久信徒，同时赠予**死神圣洁长袍**。

## 高效刷取与消费神之泪

本**幼神攻略**的核心循环在于收集神之泪以转动商人的奖励转盘。神之泪是终局阶段最重要的货币，用于解锁错过的戒律法条、专属信徒外观和强力圣物。

### 神之泪的获取途径
- **圣战小Boss与Boss**：击败任何强化版圣战Boss都会必定掉落一枚神之泪。
- **炼狱模式（Purgatory）**：成功完成每日炼狱挑战即可获得神之泪，且不会推进基地的时间流逝。
- **忠诚度升级**：将高虔诚度的信徒提升至软上限以上，可获得额外的神之泪碎片。

| 转盘奖励物品 | 基础概率 | 奖池限制 | 用途 / 效果 |
| :--- | :--- | :--- | :--- |
| **被遗忘的诫告石** | 约40%（初期） | 最多24个（含DLC为28个） | 解锁互斥的教派戒律 |
| **特殊信徒形态** | 约20% | 奖池有限（抽完即止） | 解锁外观形态（如考拉、虾等） |
| **基地装饰** | 约20% | 奖池有限（抽完即止） | 宇宙与神圣风格的装饰蓝图 |
| **圣符碎片** | 约20% | 奖池有限（抽完即止） | 用于解锁剩余的圣洁长袍 |
| **稀有项链** | 替换已清空的槽位 | 无限供应 | 提供永生、恶魔加成或忠诚度增益 |

> **进阶技巧（玩家经验）：** 根据社区反馈和玩家实测，你可以在将神之泪交给神秘商人之前直接在商人面前保存游戏。如果转盘抽到了你当前不需要的物品，直接退出到主菜单并重新加载存档，即可在不损失货币的情况下重新抽取奖励。

## 终局主教重赛战斗策略

在**幼神攻略**的这一阶段，战斗难度会大幅上升。敌人造成的伤害更高，弹幕模式相互重叠，Boss战竞技场中还会频繁刷新爆炸性修正词缀。

### 优化后的终局配装推荐
为了迅速解决强化版主教，请在踏入传送门前调整好你的配装构建。

| 配装要素 | 推荐选择 | 战术优势 |
| :--- | :--- | :--- |
| **圣洁长袍** | 命运之袍 / 黄金之袍 | 确保开局即获得即时塔罗牌协同，或在无伤战斗中叠加高额伤害 |
| **主要武器** | 神圣之斧 / 吸血铳枪 | 极高的高爆发单次伤害，或在持久战中提供持续生命偷取 |
| **咒术** | 命运之犬 / 神圣爆炸 | 远距离自动追踪弹幕，或在面对蜂拥杂兵时提供无敌帧 |
| **恶魔信徒** | 维斯塔（热诚） + 佩安（额外红心） | 确保频繁施放法术，同时缓冲Boss造成的瞬间爆发伤害 |

### 关键重赛战术
1. **立即清理召唤的杂兵**：在强化后的遭遇战中，刷新出的小怪往往带有精英词缀。使用大范围咒术在其封锁你的躲避路线前将其迅速清理。
2. **善用翻滚无敌帧（I-Frames）**：Boss的弹幕密度几乎是主线战役的两倍。面对定向爆发攻击时，应依赖翻滚的无敌时间，而非单纯依赖走位拉开距离。
3. **利用炼狱模式进行练习**：充分利用每日的炼狱挑战。在你挑战炼狱时，教派基地的时间会完全静止，这能让你在熟悉Boss攻击节奏的同时，不必担心家中的信徒挨饿或生病。

## 常见问题解答 (FAQ)

### 《咩咩启示录》中的“幼神”任务线是如何触发的？
该任务线会在你在主线剧情中击败“待终冠主”后立即开启。返回圣战传送门区域时，神秘商人（`???`）便会出现，称呼你为“幼神”，并解锁通关后的圣战重赛内容。

### 我可以从神秘商人那里获得多少个被遗忘的诫告石？
在游戏基础版本中，你最多可以从神秘商人处获得24个被遗忘的诫告石。如果你安装了大型扩展包（如 Woolhaven DLC），该上限会提升至28个，足以让你解锁教派中所有原本互斥的戒律法条。

### 在此攻略流程中，我可以将四位主教都招募为信徒吗？
可以。遵循本篇**幼神攻略**并在各自的圣战区域中第二次击败每位主教，就能净化他们的灵魂。被击败后，他们将以身着专属信徒外观的独特传奇信徒身份出现在你的教派基地中。

### 与商人交谈时如果没有神之泪会发生什么？
如果你在背包中没有神之泪的情况下与神秘商人互动，他们会用严厉的对话打发你，警告你不要试图欺骗他们。这不会带来任何负面状态惩罚；只需再去完成一次圣战或通关炼狱获取更多神之泪后返回即可。
